# Now Playing for Command Palette

A [PowerToys Command Palette](https://learn.microsoft.com/windows/powertoys/command-palette/overview) extension
that shows the media that is playing (Spotify, YouTube in the browser, and anything else that reports to the
Windows media controls) as a band on the Command Palette **Dock**, with Previous, Play/Pause and Next buttons.

> Unofficial community project. Not affiliated with or endorsed by Microsoft, Spotify or Google.

## Features
- **Dock band** with the album art, track title and artist, plus icon-only **Previous**, **Play/Pause** and
  **Next** buttons (Play/Pause switches its icon with the state).
- **Details popup**: click the track info on the Dock to open a popup with large album art, title, artist,
  album and app, a **click-to-seek bar** (click anywhere on the bar to jump there), the elapsed / total time,
  and buttons for Previous, **-10s**, Play/Pause, **+10s** and Next. The bar and time update live while playing.
  The bar and the +-10s buttons are hidden for players that do not report a seekable timeline.
  Right-click (or Ctrl+K on) the track info for Play / Pause, Previous and Next.
- Follows the system's current media session automatically and updates live (track, artist, art, play state).
- **Now Playing** command in Command Palette: lists every media session (Spotify, browser tabs, ...) with its
  track, artist, app and state. **Enter** opens the details popup for that session; **Ctrl+K** offers
  Play / Pause, Previous and Next.
- Falls back to a music note icon when a track has no album art, and shows "Nothing playing" when idle.

Notes:
- Command Palette has no slider control, so there is no draggable seek handle: the seek bar is made of 20
  clickable segments.
- Tooltips are not shown for the icon-only Dock buttons.
- Tip: set the Dock size to **Compact** in Command Palette settings for smaller buttons.

Privacy: the extension only reads what Windows already shows in its media overlay (title, artist, album art)
and sends play/pause/skip commands to the player. Nothing leaves your machine.

## Requirements
- Windows 10 19041+ or Windows 11 with PowerToys Command Palette.
- A Command Palette version with Dock support, and the **Dock enabled** in Command Palette settings.
- A player that integrates with the Windows media controls (Spotify, Edge/Chrome/Firefox media, VLC, Media Player, ...).

## Install
1. From the [latest release](https://github.com/xmsadik/now-playing-cmdpal/releases/latest) download
   `NowPlayingDev.cer` and `NowPlaying_<version>_x64.msix` (Intel/AMD) or `NowPlaying_<version>_arm64.msix` (Arm).
2. Trust the certificate once, in **PowerShell as Administrator**:
   ```powershell
   Import-Certificate .\NowPlayingDev.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople
   ```
3. Install: `Add-AppxPackage .\NowPlaying_0.1.0.0_x64.msix`
4. In Command Palette run **Reload**.

## Pin the band to the Dock
1. Make sure the Dock is enabled: Command Palette **Settings > Dock**.
2. In **Settings > Dock**, add the **Now Playing** band to the Dock. Alternatively, right-click the Dock and
   choose **Edit Dock**, then use the **+** button to add it (or right-click the item and choose **Pin to Dock**).
3. The band stays pinned across restarts.

Tip: give the **Now Playing** command an alias in Command Palette settings to jump straight to the session list.

## Build from source
```powershell
dotnet test tests\NowPlaying.Tests
.\scripts\dev-deploy.ps1          # build Debug x64 and register the package (needs Developer Mode)
.\scripts\dev-deploy.ps1 -Remove  # unregister
.\scripts\pack.ps1 -Platform x64 -Sign   # signed Release MSIX in dist\
```
Icons are generated by `python scripts\make-icons.py` (needs Pillow).

## Troubleshooting
- **The band is not in the Dock settings:** enable the Dock in Command Palette settings, update PowerToys to a
  version with Dock support, and run **Reload** after installing.
- **Buttons do nothing:** some players only accept commands while a track is loaded; start playback in the app once.
- **"Nothing playing" although music is playing:** the player does not report to the Windows media controls.
  Check that the media overlay (volume flyout) shows the track.
- Errors are logged to `diag.log` under `%LOCALAPPDATA%\Packages\NowPlaying_*\LocalCache\Local\NowPlaying\`.
